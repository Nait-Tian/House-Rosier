House Rosier — Round 2 P1 Reliability Pass
2026-09-10

Implemented P1 fixes from Round 2 playtest feedback:

1) Mobile layout hardening
- Explicit 320 / 360 / 390-430 / <=640 CSS behavior.
- Five HUD actions remain one row; minimum 44px touch height in portrait.
- No horizontal page overflow.
- Sheets/modals use dynamic viewport height + safe-area insets.
- Choice lists scroll independently on short screens.
- Free Chat input is sticky and uses 16px input text to avoid iOS focus zoom.
- Landscape short-screen rules added.

2) Portrait/render timing hardening
- Character portraits now use the shared decoded preload promise.
- Late portrait loads are discarded if the scene has already changed character.
- Existing decoded background preloading/crossfade behavior retained.

3) NPC-specific knowledge scopes
- LORE now supports explicit `knownBy` allow-lists.
- AI lore injection checks both unlock state and active NPC knowledge scope.
- Sensitive entries such as the chalk-circle anomaly and household details no longer leak to unrelated characters simply because global lore is unlocked.
- Identity interpretation entry remains ai:false.

4) Compact AI context packet
- Free Chat uses: immutable world rules + active character card + current state + this NPC's validated conversation memories + allowed relevant lore + last 6 chat turns.
- Summarization window reduced to the most recent 10 turns.
- Explicit prompt rule: character knowledge is local, not globally shared.

5) Free Chat cannot pre-play authored events
- System rules explicitly prohibit initiating/completing future invitations, outings, investigations, experiments, political decisions, confessions, promises, or route milestones.
- Free Chat remains non-canonical and cannot mutate story state.

6) Map/schedule double-commit guard
- Schedule choice commits only once and disables sibling buttons immediately.
- Prevents double taps on mobile from applying relationship/route effects twice.

7) BYOK/debug privacy hardening
- Raw API key remains absent from exports.
- Debug input snippets are now redacted by default.
- Player may explicitly opt in to including short prompt snippets.
- Added in-settings debug preview before export.
- Model migration now uses a central migration table instead of a one-off condition.
- Connection Test remains isolated from story GameState.
