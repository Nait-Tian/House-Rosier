# IDENTITY PORTRAIT UNIFICATION v0.2.8

This patch replaces the identity carousel portraits for male / female / nonbinary Nait with a newly unified portrait set.

## Goals
- Use the existing nonbinary Nait portrait direction as the mother style.
- Rebuild the male and female options to match the same visual fidelity, lighting, framing, and costume language.
- Keep Nait’s core identity consistent across all three options: deep red hair, blue-green eyes, pale refined features, white aristocratic clothing, and teal brooch.

## Asset Changes
Replaced:
- `assets/identity/nait_male.webp`
- `assets/identity/nait_female.webp`
- `assets/identity/nait_nonbinary.webp`

## Visual Direction
- **Male**: shorter layered deep-red hair; elegant young-master presentation.
- **Nonbinary**: refined androgynous long-hair portrait; retained as the base direction.
- **Female**: long flowing deep-red hair with restrained floral detail; elegant my-lady presentation.

## Notes
No gameplay, text, or logic changes were made in this patch. Only the identity carousel portrait assets were updated.
