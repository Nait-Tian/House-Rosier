# House Rosier — Identity Carousel Patch v0.2.7

Scope: opening identity / gender-expression selection screen only.

## Changes

- Replaced the three text buttons with a three-portrait carousel.
- Male presentation uses a short-haired Nait portrait and `young master` as the title.
- Female presentation uses a long-haired Nait portrait and `my lady` as the title.
- Nonbinary presentation keeps the existing Nait portrait and uses `lord` / `Lord Nait`.
- The selected portrait is centered, larger, and shown in full color. Side portraits are smaller, greyed, and lower-opacity.
- Supports tapping side portraits, arrow buttons, and horizontal swipe gestures.
- The description panel updates with the active selection.
- Added a second-step confirmation modal before a new game, prototype game, or legacy-save gender migration begins.
- Confirmation text uses the compact requested title format: `称呼：young master`, `称呼：my lady`, or `称呼：lord`.
- Existing fixed premise is preserved: Nait Rosier remains the sole Rosier heir and an Omega; only gender expression, pronouns, and title choice change.

No Week 1 narrative flow, flags, affinity values, memory fragments, or post-Day-7 content were changed by this patch.
